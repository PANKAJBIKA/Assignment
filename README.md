 Collaborative Workspace Backend

A production-style backend application built using **Spring Boot**, demonstrating
authentication, real-time collaboration, caching, and asynchronous processing.

This project is designed to help understand **end-to-end backend development**
using modern Java technologies.

---

## 🚀 Tech Stack

- **Java 17**
- **Spring Boot 3.x**
- **Spring Security + JWT**
- **MySQL** – relational database
- **Redis** – caching
- **Apache Kafka** – asynchronous job processing
- **WebSocket (STOMP)** – real-time communication
- **Swagger (OpenAPI 3)** – API documentation
- **JUnit 5 + Mockito** – unit testing
